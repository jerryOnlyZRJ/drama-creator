# Drama Creator Liquid Glass UI/UE 产品设计规格

版本：v1.0
日期：2026-06-14
适用范围：Drama Creator Tauri + Web 前端 V1 重设计
依据：`docs/prd-drama-creator-redesign.md`、`docs/v1-production-closed-loop.md`、`docs/adapter-contract.md`、`docs/prompt-best-practices.md`、`DESIGN.md`、项目本地 `drama-creator` skill、Liquid Glass skill

## 1. 设计目标

Drama Creator 的 V1 界面应像一个本地桌面生产工作台，而不是网站首页、资源浏览 demo 或开发工具面板。用户打开应用后，第一屏就能继续项目或新建项目；进入项目后，始终围绕 4 个步骤推进：

```text
剧本与分镜 -> 公共资产 -> 分镜视频 -> 成片导出
```

本设计借鉴 macOS Liquid Glass 的层级、通透、前景激活和工具栏组织原则，但当前应用是 Tauri WebView，不是 SwiftUI。设计不得要求 `NavigationSplitView`、`glassEffect`、系统 toolbar 或 SwiftUI sheet；应转译为 Web 可实现的 CSS、HTML 结构和交互规则。

核心约束：

- 首屏是可执行项目库，不做营销页。
- 面向创作者表达，不把目录、JSON、adapter id、内部 schema 暴露给非技术用户。
- 所有页面的按钮、输入框、说明文案、状态提示、错误提示和空状态都必须使用非技术用户可理解的业务语言。
- 工作流优先于配置。模型缺失时仍能手动编辑、复制提示、外部生成、导入回填和导出。
- AI 功能入口不能因为未配置模型、未授权或自动化不可用而消失；必须在原位置展示不可用状态、配置引导和手动替代操作。
- 不把教程、操作指引、小贴士或创作教练作为独立常驻模块。生产级主界面只展示真实工作对象、状态和操作；必要说明应收敛为就地短提示、空状态、错误状态、确认弹窗或默认收起帮助。
- 分镜视频主视图使用卡片网格，状态角标在卡片上呈现。
- 即梦自动化是外部跳转提效路径，必须使用 Drama Creator 托管浏览器 profile，提交前停下等待用户确认。
- 回收站、导出、模型凭据必须按生产级应用处理，避免开发期心智泄漏。

## 2. Liquid Glass 到 Web/Tauri 的转译原则

### 2.1 可转译的原则

| Liquid Glass 原则 | Web/Tauri 转译 | 使用范围 |
|---|---|---|
| 系统结构优先 | 先保留语义 HTML、原生表单、`dialog`、sticky toolbar，再加材质 | 全局 |
| toolbar 自动分组 | 使用 `.app-bar`、`.command-bar`、`.segmented-control` 分组，按钮间用固定 gap 和分隔线表达关系 | 顶栏、画布工具条、导出工具条 |
| search 放在作用域容器 | 搜索框跟随其筛选对象：项目库搜索项目，公共资产库搜索资产，分镜视频搜索分镜 | 项目库、公共资产库、分镜视频、回收站 |
| 语义 tint | 颜色只表达主操作、成功、警告、危险、当前选择，不做装饰性彩色玻璃 | 所有控件 |
| foreground activation | 当前任务面板、当前分镜、当前 step 有更清晰边框、阴影和标题权重 | 工作台、画布、卡片网格 |
| glass grouping | 相邻浮动工具合并在同一个 glass 容器里，不散落多个半透明块 | app bar、step rail、画布浮层 |
| motion continuity | 展开 sheet、打开 inspector、切换 step 使用短转场表达来源和去向 | 新建项目、即梦投喂包、资源详情 |

### 2.2 不照搬的内容

- 不使用 SwiftUI 专属 API 名称作为实现要求，例如 `glassEffect`、`GlassEffectContainer`、`ToolbarSpacer`。
- 不把整个页面做成模糊玻璃。大量表格、长文本、提示词、媒体网格仍以清晰实底或轻透明 surface 为主。
- 不为了 Liquid Glass 把高密度工具界面改成大卡片 landing page。
- 不使用过强背景图、彩色渐变球、装饰性模糊层。媒体素材本身才是视觉重点。

### 2.3 Web 设计令牌建议

只在文档中定义，后续实现时再落 CSS：

```css
:root {
  --dc-bg: #f6f7fb;
  --dc-bg-elevated: #ffffff;
  --dc-glass: rgba(255, 255, 255, 0.72);
  --dc-glass-strong: rgba(255, 255, 255, 0.84);
  --dc-glass-border: rgba(15, 23, 42, 0.12);
  --dc-glass-highlight: rgba(255, 255, 255, 0.62);
  --dc-shadow-float: 0 10px 34px rgba(15, 23, 42, 0.12);
  --dc-shadow-tight: 0 4px 14px rgba(15, 23, 42, 0.08);
  --dc-blur: 18px;
  --dc-radius-sm: 6px;
  --dc-radius-md: 8px;
  --dc-radius-lg: 12px;
  --dc-accent: #2563eb;
  --dc-success: #11845b;
  --dc-warning: #b76e00;
  --dc-danger: #b42318;
  --dc-info: #047481;
}
```

实现要求：

- glass surface 使用 `background: var(--dc-glass)`、`backdrop-filter: blur(var(--dc-blur)) saturate(140%)`、`-webkit-backdrop-filter`。
- 必须提供 `@supports not (backdrop-filter: blur(1px))` fallback，退化为不透明 surface。
- 必须支持 `prefers-reduced-transparency`：关闭透明采样，改为 `--dc-bg-elevated`。
- 动效时长控制在 120-180ms，支持 `prefers-reduced-motion`。
- 主要容器和卡片半径不超过 8px；sheet 可用 12px。状态 pill 可用全圆角。

## 3. 信息架构

```text
Drama Creator
├── 项目库
│   ├── 新建项目
│   ├── 最近项目
│   └── 项目状态概览
├── 项目工作台
│   ├── 分集切换
│   ├── Step 1 剧本与分镜
│   ├── Step 2 公共资产
│   ├── Step 3 分镜视频
│   └── Step 4 成片导出
├── 单分镜画布
│   ├── 剧本资源族
│   ├── 素材资源族
│   ├── 产物资源族
│   └── 资源详情 / QC
├── 设置
│   ├── 存储与回收站概览
│   ├── 文本模型
│   ├── 图片模型
│   ├── 视频模型
│   └── 即梦托管浏览器状态
└── 回收站
    ├── 项目
    ├── 分集
    └── 资源
```

导航规则：

- 顶部 app bar 始终显示当前位置：项目库 / 项目 / 分镜 / 设置 / 回收站。
- 项目工作台内不再保留旧 tab 心智，4-step 是唯一主导航。
- 单分镜画布从分镜卡片进入，返回时回到 Step 3 并保留筛选/滚动位置。
- 设置和回收站属于全局工具入口，不嵌入项目 step。

## 4. 全局布局规范

### 4.1 App Shell

```text
┌────────────────────────────────────────────────────────────┐
│ glass app bar: brand / crumbs / scoped actions             │
├────────────────────────────────────────────────────────────┤
│ page-specific content                                      │
│                                                            │
├────────────────────────────────────────────────────────────┤
│ status footer: save state / counts / warnings              │
└────────────────────────────────────────────────────────────┘
```

- `.app-bar` 是 glass surface，sticky top，承载品牌、面包屑、当前页主要动作。
- `.app-status` 是低调状态栏，显示保存状态、计数、当前操作结果，不放业务主按钮。
- 页面主内容用 `minmax(0, 1fr)` 防止文本撑破布局；媒体区用固定 aspect ratio。

### 4.2 密度与栅格

- 桌面默认宽度 1280-1728px，核心布局以 12px gutter 和 4px baseline 推进。
- 项目库、公共资产库、分镜视频使用自适应网格：`repeat(auto-fill, minmax(240px, 1fr))`。
- 单分镜画布桌面三列：剧本 280-320px、素材 1fr、产物 1fr，右侧 inspector 320-360px。
- 窄视口下，inspector 改为底部 sheet；分镜画布三列改为横向 section 或垂直堆叠。

### 4.3 文案原则

- 本原则覆盖项目库、项目工作台、公共资产、分镜视频、单分镜画布、模型设置、回收站、导出、弹窗、空状态、错误提示和所有表单控件，不是设置页专项要求。
- 对用户说“新建项目”“导入外部资源”“复制上传清单”“设为当前版本”。
- 不在主流程说“绝对路径”“JSON”“adapter”“schema”“CDP”“localhost”。
- 需要给高级用户的技术详情放进“高级 / 排障信息”折叠区，默认收起。
- 即梦投喂包的用户可见命名应是“投喂信息”或“上传清单”；`JSON` 只作为高级导出格式，不作为主按钮文案。

## 5. 页面设计

### 5.1 项目库

目标：用户能在 2 分钟内新建项目并进入第 1 集，也能看懂最近项目停在哪一步。

布局：

```text
app bar: Drama Creator / 项目库 / 设置 / 新建项目
main:
  左上：最近项目标题 + 搜索
  右上：状态概览 3 个 compact metric
  下方：项目卡片网格
status footer: 项目读取状态 / 本地工作台版本
```

项目卡片：

- 标题、最近更新时间、当前 step、分镜完成数、导出状态。
- 单击卡片进入项目，不再单独放“打开”按钮。
- 卡片右下角只保留垃圾桶图标按钮；点击后进入页内二次确认，再次点击才移入回收站。
- 只显示“应用项目 / 已注册项目”这类业务来源，不显示完整目录。
- 删除应用自有项目进入回收站；外部注册项目按钮文案为“从列表移除”。

状态：

- 空项目：中心空态，主按钮“新建项目”。
- 读取失败：显示可读错误和“重试”。
- 项目缺失或不可访问：卡片显示“需要重新选择”，不暴露内部路径，详情折叠区可显示原位置。

### 5.2 新建项目

使用 `dialog` sheet，来源为 app bar 的“新建项目”按钮。sheet 是强 glass surface，但表单区域保持清晰白底。

步骤不做复杂 wizard，使用一张紧凑表单：

1. 项目名称。
2. 起点 segmented control：“从想法开始”“从故事开始”“从已有素材开始”，默认“从想法开始”。
3. 输入区：粘贴一句想法、故事、剧本、分镜说明或素材描述。
4. 本地文件导入入口：按钮为“导入文本或素材”，使用 Tauri 原生选择器；浏览器 fallback 才显示文件输入。

首集不在新建 sheet 内命名；应用自动创建“第 1 集”，后续多集管理放在项目内完成。

交互：

- 项目名为空时禁用“创建并进入”。
- 选择“从想法开始”时，输入区显示“生成完整故事”按钮；文本模型可用时将一句想法扩写成完整故事，未配置时显示“去配置文本模型”和手动补写路径。
- 选择“从已有素材开始”时，输入区 placeholder 改为“描述已有素材和想生成的视频方向”。
- 创建失败时错误显示在 footer 上方，不关闭 sheet。
- 创建成功直接进入项目工作台 Step 1。

### 5.3 项目工作台 4-step

布局：

```text
app bar: 项目名 / crumbs / 轻量页面操作
main:
  episode selector row: 当前分集下拉 / 新建分集
  workflow glass rail: 1 剧本与分镜 | 2 公共资产 | 3 分镜视频 | 4 成片导出
  content:
    primary work area
    contextual status only: 缺失前置条件 / 当前警告 / 直接行动按钮
status footer
```

Step rail 规则：

- 每个 step 有状态：未开始、可进入、当前、已确认、有警告、被阻塞。
- 用户可以跳转 step，但跳过必须来自“已确认”或“已导入”状态。
- 阻塞不使用禁用灰按钮作为唯一反馈，必须给出原因和下一步。
- AI 操作不可用时，主按钮可以进入“需配置”状态，但旁边必须有“去配置”和“继续手动”入口，避免用户误以为功能不存在；文本生成与分镜拆分场景下，如果订阅授权和 API Key 都不可用，“去配置”必须是按钮并跳转 `settings.html` 的文本模型配置区。
- 不为 step 单独设置右侧教学栏或“下一步建议”卡片；step 的状态、阻塞原因和行动按钮必须贴在发生问题的业务区块里。

分集切换：

- 分集入口必须避免同一页面出现两套导航。若当前 Step 使用下拉选择分集，则不再展示 ep001/ep002 这类 chip/icon 列表。
- Step 3「分镜视频」默认使用“当前分集下拉 + 同行靠右新建分集”布局，给分镜卡片网格保留最大横向空间。
- chip 显示分集名、分镜数、导出状态。
- 只有 1 集时不展示“删除分集”；删除提示引导到删除项目。
- 新建分集打开小 sheet：分集名称 + 复制公共资产引用选项。

#### Step 1：剧本与分镜

推荐布局：

```text
作品元数据
故事源 | 分镜剧本
```

作品元数据固定在顶部。故事源和分镜剧本组成同高的写作对照工作台，在桌面宽度下并列，方便用户同步检查纯故事原文和逐镜分镜剧本；内容区各自滚动，避免短内容卡片下方出现大块空白。中窄屏下回落为单列。分镜剧本是唯一可见剧本层，不再额外展示完整剧本草稿、分集剧本或分镜预览卡片。

交互：

- 作品元数据显示作品名、核心立意、当前分集、分集编号、当前步骤、剧本状态、分镜数量等可读摘要；核心立意和全局设定可直接编辑保存，不暴露目录或 JSON 文件路径。
- 角色、场景、关键道具和公共创作约束收敛到作品元数据的全局设定，不能在每个分镜里重复铺陈。
- 故事源可保存、导入本地文本。
- 文本模型可用时，系统可从故事源生成分镜剧本；未配置 AI 能力时，“生成分镜剧本”入口仍保留并提示配置，用户必须能手动编写或粘贴分镜剧本。
- 分镜剧本直接按 `S001 分镜｜10s｜标题`、`S002 分镜｜15s｜标题` 顺序展示，每个分镜下面只写该镜头的画面、动作、对白/旁白、声音等可读剧本内容。
- 分镜剧本不展示粗分镜/细分镜层级，不展示覆盖分镜、场景节点、依赖资源、生成备注或视频提示词。
- 保存分镜剧本后，每个分镜必须携带自己的剧本片段；后续分镜视频、单分镜画布、分镜提示词和成片字幕都以该分镜片段作为默认输入，而不是回读整集剧本。
- 兼容旧数据时，如果分镜缺少剧本片段但已有分镜视频提示词，应用可自动补齐可读片段；界面仍只展示面向创作者的“剧本片段”，不暴露迁移或内部字段。
- 版本只保留当前确认版和上一版，入口文案为“恢复上一版”。
- 分镜确认后生成资产依赖候选，进入 Step 2。

#### Step 2：公共资产

公共资产库是项目级，不混入分镜临时资产。
兼容旧项目时，`scripts/assets/style-refs` 只作为显式项目级风格锚点来源；分镜关键帧、尾帧、标题图、UI 截图等单镜头素材不得自动显示在公共资产库。
公共资产库页面不展示分集切换列表，也不展示“新建分集”入口；分集管理只出现在剧本与分镜、分镜视频、成片导出等分集相关 Step。

布局：

```text
toolbar: 搜索 / 类型 tabs / 筛选 chips / 批量操作
grid: 公共资产卡片
right inspector: 选中资产详情 / 可编辑字段 / 质量提示
```

Tabs：

- 全部、角色、场景、道具、风格参考、音频参考、视频参考。

检索：

- 只保留类型 tabs 和搜索框，不展示已绑定、未绑定、必需、可选、AI 生成、外部导入、手动上传等第二排状态标签。

选中资产详情：

- 用户点击任意公共资产卡片后，右侧展示资产详情 inspector，不跳转页面。
- Inspector 必须展示媒体预览、资产名称、分类、状态、必需性、描述、提示词、引用资源、标签、关联分镜、参考用途和素材来源。
- 用户可以直接编辑上述字段，并通过“保存资产”写回公共资产本体。
- 保存后所有分镜仍通过公共资产引用读取，不复制为分镜临时资产。
- 详情页提供“移入回收站”危险按钮；首次点击进入确认态，再次点击才执行。被分镜引用的资产不能直接删除文件，需要给出就地提示。
- 如果没有选中资产，右侧展示质量提示、必需资产缺失和合并重复建议。

资产卡片：

- 缩略图或类型图标、标题、类型、标签、关联分镜数、状态。
- 音频参考卡片和右侧详情预览必须使用音频相关封面（例如声纹、波形、唱片视觉）承载原生播放控件，不能显示成通用斜纹占位块。
- 缺失但非必需：黄色质量提示，不阻塞。
- 必需且缺失：红色阻塞标记，只阻塞引用它的分镜。
- “合并重复”是 P1 操作，必须二次确认合并目标。

#### Step 3：分镜视频卡片网格

前置兜底：

- 如果当前分集没有分镜剧本或尚未保存分镜，Step 3 不展示空白网格。
- 使用居中的状态卡说明原因，并提供主按钮“返回剧本与分镜”。
- 点击后切回 Step 1，并把焦点放到故事源或分镜剧本入口。

布局：

```text
episode row: 当前分集下拉 / 新建分集（不展示分集 chip/icon list）
toolbar: 搜索编号/标题 / 状态筛选 / 批量生成方式
shots grid: cards
right coach: 当前缺失 / 即梦门禁说明 / 手动回填入口
```

分镜卡片必须展示：

- 缩略图或空态。
- 分镜编号、标题。
- 比例、时长。
- 当前版本：无 / v001 / 候选待确认。
- 状态角标。
- QC 状态。

状态角标：

- 未生成、准备投喂、处理中、待质检、需重跑、已通过。
- 自动化执行、已提交、待下载、待回填等中间态在主界面统一归并为“处理中”。

卡片交互：

- 单击打开单分镜画布。
- 状态 badge 可 hover 展示解释。
- 卡片底部允许一个主行动作：例如“打开画布”“继续回填”“查看 QC”，避免每张卡片堆满按钮。

#### Step 4：成片导出

成片导出只在独立 step 出现，不在其他页面常驻。

布局：

```text
左：导出检查 + 分镜顺序
中：分镜拼接预览 + 字幕预览 + 字幕设置
右：导出设置 + 结果列表
```

内容：

- 分镜顺序、当前成片版本、QC 状态、缺失视频提示。
- 分镜拼接预览：按分镜顺序拼接当前可用的视频片段，缺失分镜不进入预览，且不改变正式导出的阻塞状态。已标记为精选的剪辑修复版 assembly 覆盖整集时直接播放，覆盖局部连续分镜时作为已固化时间线片段替换对应分镜区间，再继续拼接后续分镜。
- 字幕预览：只取对白、旁白、显式屏幕文字。
- 设置：画幅、是否生成字幕版。
- 导出结果列表：原片、字幕版、SRT。
- 主流程标题、按钮、错误和空状态必须使用中文创作者文案，例如“导出准备 / 字幕样式 / 导出文件”，不能暴露 `Export Output`、`Missing videos` 或类似工程文案。

导出规则呈现：

- 缺失视频：阻塞导出，按钮禁用，清单定位缺失分镜。
- 未质检：允许导出草稿版，黄色 warning。
- 需重跑：允许导出草稿版，红色 warning。
- 全部通过：导出正式版。
- 字幕烧录失败：保留原片和 SRT，结果区显示 warning，不把整个导出视为失败。

### 5.4 单分镜画布

单分镜画布是生产工作页，不是调试图谱页。

配套 PRD 原型图：本文对应页面的文字要求。审核时以“生产工作页”而不是调试图谱作为判断标准，并保留顶部镜头动作、三列资源族画布、右侧详情/QC inspector 和底部状态/缩放。

布局：

```text
app bar:
  crumbs: 项目库 / 项目 / s001
  actions: 上一镜头 / 下一镜头 / 添加参考资源 / 导入外部资源 / 投喂信息 / 提交到即梦生成

body:
  canvas:
    column 1 剧本资源族
    column 2 素材资源族
    column 3 产物资源族
  inspector:
    媒体预览 / 详情 / 操作 / QC

footer:
  保存状态 / 资源数 / 依赖数 / 缩放
```

画布规则：

- 三列标题固定：剧本、素材、产物。
- 连线表达引用和生成关系，选中节点后高亮相邻路径。
- 节点内容显示业务名和状态，不显示内部文件路径。
- 路径、节点 id、投喂原始结构只在 inspector 的“高级 / 排障信息”折叠区。
- Inspector 的提示词区域必须单独成组，标题直接写“提示词”，并提供“引用资源”按钮打开当前镜头参考资源管理。

参考资源管理：

- “添加参考资源”打开 picker sheet。
- 当前参考列表是有序列表，顺序决定 `@图片N` 映射，但 UI 文案用“上传顺序 1/2/3”。
- 可添加、替换、排序、移除引用；移除引用不删除资产文件。
- 从公共资产引用时只创建引用关系，不复制业务资产身份。

即梦投喂信息：

- 主按钮文案：“提交到即梦生成”；“投喂信息”是人工核对和复制兜底入口。
- sheet 内主区显示：提示词、上传清单、门禁、警告。
- 主操作：提交到即梦生成；辅助操作：复制提示词、复制上传清单。
- 高级折叠区：复制完整投喂数据。这里可以输出 JSON，但默认收起，不作为非技术主路径。

手动回填：

- “导入外部资源”默认使用 Tauri 文件选择器。
- 用户选择图片、视频、音频、文本后，指定用途：参考图、候选视频、音频参考、备注文本。
- 视频默认进入候选对比版本，不自动替换当前版本。
- 用户点击“设为当前版本”后，候选和当前按 V1 规则交换。

QC：

- Inspector 固定提供 QC segmented control：待质检、需重跑、已通过。
- 备注框用于记录构图问题、重跑建议或验收结论。
- 只有视频产物或当前成片版本可保存 QC；其他节点显示只读说明。

### 5.5 模型设置

设置页按能力组织，不按服务商或 adapter id 组织。

配套 PRD 原型图：本文对应页面的文字要求。审核时以“按能力分组、按需要配置或执行的方式聚类、非技术文案、失败后可手动降级”为判断标准。

布局：

```text
app bar: 设置 / 返回项目库
main:
  storage summary
  文本模型 section
  图片模型 section
  视频模型 section
  即梦托管浏览器 section
```

每个能力 section：

- 当前默认通道。
- 可配置或可执行通道卡片：
  - 订阅授权。
  - API Key。
  - 浏览器自动化。
- 兜底入口：手动外部生成后导入。它不是设置项，不需要配置；当订阅授权、API Key、浏览器自动化均不可用或执行失败时，在业务页面提供导入回填路径。
- 状态：未配置、已配置、测试通过、测试失败、不可用、当前默认。
- 操作：配置、测试连接、设为默认、清除授权。

文案：

- 不用“OpenAI 兼容文本”作为主标题；可写“API Key 文本模型”，说明里再列 GPT / Claude / 国内常用 / 本地 Ollama。
- Claude、DeepSeek、千问、豆包、Kimi、智谱、Gemini、Grok、Ollama 等服务商都归入 API Key 聚类；服务商下拉只是预填字段，自定义服务商必须和预设同级保留。
- 当业务入口因缺少文本模型能力进入“需配置”状态时，“去配置”应跳转 `settings.html#model-text`；图片、视频与音频同理跳转对应能力区。若所有可配置或可执行方式均不可用或失败，页面降级到手动外部生成后导入，不要求用户配置一个“手动外部生成”通道。
- 订阅授权是通用方式；当前只展示已实现平台。
- 订阅授权和已验证 API Key 的模型使用应用已验证的候选下拉，不让用户手动输入模型 ID；自由模型 ID 仅保留给 API Key 自定义端点或服务商临时未返回模型目录的兜底场景。
- 图片订阅未实现时不得展示为可用。
- 设置页不能额外放置常驻的“配置指引”“素材生产模式说明”或大块 OAuth Notice 模块；生产方式只用卡片标签表达，较长合规文案放入“合规说明”，且合规说明默认收起。
- 即梦自动化显示为视频和音频生成推荐通道，说明它会打开 Drama Creator 托管窗口。

凭据安全：

- API Key 输入使用密码框，保存后只显示“已保存到系统钥匙串”。
- 服务地址、默认模型、文档链接可明文展示。
- 不在 UI 或日志展示 token、完整 key、refresh token。

### 5.6 回收站

配套 PRD 原型图：本文对应页面的文字要求。审核时以“全局回收站管理页”作为判断标准，不要把它嵌进某个项目 step；页面必须同时表达恢复、永久删除、清空二次确认和可释放空间。

布局：

```text
summary: 总项数 / 可释放空间
toolbar: 搜索 / 类型筛选 / 清空回收站
workspace: 左侧回收站条目 / 右侧详情与确认面板
```

条目：

- 标题、类型、大小、删除时间、来源摘要。
- 主列表默认不显示完整绝对路径；右侧详情面板可查看恢复位置。
- 操作：恢复、永久删除。

交互：

- 恢复、永久删除单项必须使用页内二次确认，不使用原生 `window.confirm`。
- 清空回收站必须使用页内二次确认，并展示预计释放空间。
- 恢复冲突时给出清晰提示并停止恢复，不静默覆盖现有内容。

## 6. 核心交互流程

### 6.1 无模型配置流程

1. 用户新建项目，可以只输入一句想法；文本模型可用时应用生成完整故事，未配置时引导配置或由用户手动补写完整故事。
2. 所有 AI 入口仍在对应上下文显示为“需配置”或“当前不可用”，并给出配置入口。用户没有保存默认文本模型时，文本能力优先尝试订阅授权，再尝试 API Key；用户保存了默认文本模型后，生成必须使用该模型或提示其不可用，不得静默切换到其他服务商。两者都不可用时，页面提供“去配置”按钮跳转 `settings.html` 的文本模型配置区。
3. 用户选择不配置时，手动编写或粘贴分镜剧本；也可以使用外部工具生成后粘贴回来。
4. 公共资产库显示待生成资产，但不全局阻塞；资产生成按钮仍显示不可用原因和导入入口。
5. 分镜视频卡片显示“未生成”或“处理中”。
6. 用户进入单分镜画布，复制提示词或上传清单到外部平台。
7. 用户下载外部生成结果，通过“导入外部资源”回填。
8. 视频进入候选版本，用户设为当前并 QC。
9. 所有分镜有当前视频后进入导出。

验收点：无任何模型配置时，界面不能把用户卡死在设置页，也不能隐藏 AI 功能入口。

### 6.2 即梦门禁流程

1. 用户在单分镜画布点击“提交到即梦生成”。
2. 应用按全局视频模型配置启动托管即梦窗口，并准备单镜头安全提示词、上传顺序、比例/时长、门禁。
3. 用户也可打开“投喂信息”，复制提示词和上传清单作为人工 fallback。
4. 自动化打开 Drama Creator 托管即梦窗口；首次使用提示用户在该窗口登录。
5. 自动化尝试进入视频生成、设置模型/比例/时长、上传参考图。
6. 自动化必须通过即梦页面候选列表把引用绑定为真实资源 chip。
7. 如果 raw `@图片N` 仍存在，或 chip 数量/顺序不可验证，状态停在“需要手动绑定参考”，并给出修复提示。
8. 自动化到提交前必须停下，用户目检后手动提交。
9. 生成完成后，用户手动下载并回到 Drama Creator 回填。

验收点：界面不能暗示 V1 会自动提交、自动等待、自动下载或自动回填。

### 6.3 手动回填流程

1. 用户点击“导入外部资源”。
2. Tauri 文件选择器打开；浏览器 fallback 才出现路径输入。
3. 用户选择资源类型和用途。
4. 如果是视频，默认进入当前分镜候选版本。
5. 用户预览后点击“设为当前版本”。
6. 原当前版本退到候选位；已有候选被覆盖前需确认。
7. 用户保存 QC。

验收点：用户不需要知道资源写到了哪个目录，也不需要手动编辑项目文件。

## 7. 组件规范

### 7.1 Glass App Bar

- 高度 56-64px。
- 左侧品牌和面包屑，中间不塞长说明，右侧只放当前页主操作。
- 使用同一 glass 背景承载一组按钮；不同动作组之间用 12px gap 或 1px 分隔线。
- 只有主动作使用 accent tint。

### 7.2 Workflow Step Rail

- 使用 4 个等宽或自适应 step button。
- 每个 step 含编号、标题、短状态。
- 当前 step 使用 accent border 和轻 glass highlight。
- 已确认 step 使用 success dot；有警告 step 使用 warning dot；阻塞 step 使用 danger dot。

### 7.3 Cards

- 项目卡、公共资产卡、分镜卡统一 8px radius。
- 卡片背景优先实底白或 `--dc-glass-strong`，媒体缩略图保持 16:9。
- 卡片 hover 只增加边框和轻 shadow，不改变尺寸。
- 卡片内文本必须两行截断或换行，不允许撑破按钮和布局。

### 7.4 Inspector

- 桌面右侧固定 320-360px。
- 内容顺序：标题、媒体预览、关键状态、操作、QC、高级信息。
- Inspector 背景比画布略强，避免透明过度影响长文本可读性。
- 高级信息默认折叠。

### 7.5 Dialog / Sheet

- 新建项目、导入外部资源、添加参考资源、即梦投喂信息使用 `dialog`。
- 背景 overlay 不用纯黑重遮罩，采用轻暗化 + blur；正文仍清晰。
- footer 固定放取消和主操作；危险操作使用 danger 按钮并二次确认。

### 7.6 Buttons

- 主按钮：实色 accent，表示“创建、保存、导出、确认”。
- 次按钮：glass/outline，表示“重载、复制、打开、测试连接”。
- 危险按钮：红色，只用于移入回收站、永久删除、清空。
- 公共资产详情里的危险按钮必须和项目卡、分镜资源删除保持一致：页内二次确认，不使用系统弹窗。
- 图标可后续引入，但按钮必须保留可读文本，避免非技术用户误解。

### 7.7 Badges

- 状态 badge 使用低饱和背景 + 高对比文字。
- 成功：绿色；警告：琥珀；阻塞/危险：红色；外部跳转/信息：青色；当前选择：蓝色。
- badge 文案使用业务语言，例如“处理中”“需重跑”“当前默认”。

## 8. 状态规范

### 8.1 工作流状态

| 状态 | UI 表达 | 行为 |
|---|---|---|
| 未开始 | muted dot | 可进入但需要用户输入 |
| 当前 | accent border + glass highlight | 展示当前 step 内容 |
| 已确认 | success dot | 可作为后续 step 输入 |
| 有警告 | warning dot | 可继续，但风险说明贴在对应卡片或区块内 |
| 被阻塞 | danger dot | 禁用下一主动作，并在同一区块给出修复入口 |

### 8.2 分镜视频状态

| 状态 | 颜色 | 主建议 |
|---|---|---|
| 未生成 | neutral | 打开画布 |
| 准备投喂 | info | 查看投喂信息 |
| 处理中 | info + progress | 等待外部生成，或完成下载/回填 |
| 待质检 | warning | 打开 QC |
| 需重跑 | danger | 复制重跑建议 |
| 已通过 | success | 可用于导出 |

### 8.3 模型与授权状态

- 未配置：灰色，主按钮“配置”。
- 已配置：蓝色，主按钮“测试连接”或“设为默认”。
- 当前默认：蓝色 badge，卡片置顶。
- 测试通过：绿色。
- 测试失败：红色，显示可读原因，不显示密钥。
- 外部手动：青色，不要求配置。

### 8.4 导出状态

- 不可导出：缺失视频，按钮禁用。
- 可导出草稿：有未质检或需重跑，按钮可用并展示 warning。
- 可导出正式版：所有分镜有当前视频且 QC 通过。
- 导出中：按钮 loading，清单锁定。
- 导出成功：结果列表显示原片、字幕版、SRT。
- 部分成功：字幕烧录失败时显示 warning 和可用文件。

### 8.5 回收站状态

- 空：显示“回收站为空”，清空按钮禁用。
- 正常：可筛选、恢复、永久删除。
- 忙碌：当前条目按钮 loading，其他 destructive 操作禁用。
- 恢复冲突：显示二次选择，不自动覆盖。
